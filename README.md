# 星际穿越 · Cosmic Flight

一个纯前端单文件的 3D 宇宙穿越网页，基于 Three.js 实现。打开 `index.html` 即可体验。

**在线体验**：https://thekeydu.github.io/cosmic-flight/

## 效果预览

- **浩瀚宇宙背景**：纯黑深空点缀程序化生成的彩色星云、斜跨天幕的银河星尘带、远景孤星
- **各式行星**：带彩色星环的土星（暗金环）、海王星（冰蓝环）、冰行星（淡青/淡紫环）、蓝色地球、红色火星、条纹木星等 9 类行星，全部由 Canvas 程序化绘制纹理，无需外部贴图
- **曲率飞行（狂野模式）**：
  - 指数爆发加速 / 渐进加速随机切换，曲速冲刺后瞬间急刹车
  - 加速时前方空间被压缩成致密"奇点区"，近处星体被拉成长星轨扫过屏幕四周
  - 急停瞬间画面反向拉伸回弹，船体前冲顿挫
  - 爆发瞬间船头猛甩向随机方向（上下左右）
- **星轨表现**：1600 颗彩色小球（恒星/小行星）高速时沿飞行方向被物理拉伸成星轨，减速后缩回圆点

## 操作方式

| 操作 | 效果 |
|---|---|
| 移动鼠标 | 环顾四周（大幅度视角偏移 + 机身滚转） |
| 点击画面 | 切换 平稳巡航 / 狂野飞行 模式 |

## 技术要点

- Three.js（r160，importmap CDN 引入），单 HTML 文件，无构建步骤
- `InstancedMesh` 实例化渲染 1600 颗星体，每帧更新拉伸矩阵
- 程序化 Canvas 纹理：行星表面（条纹/大陆/云层）、星环环缝、星云絮状结构
- 速度状态机随机编排：滑行 → 爆发加速（easeInExpo）→ 曲速 → 急刹车（easeOutExpo）
- FOV 随速度动态扩张/收缩，星云尺寸随 FOV 反向补偿
