# 星际穿越 VR · Cosmic Flight VR

基于 Three.js + WebXR 的 3D 宇宙曲率飞行模拟，支持 **Meta Quest 3** 等 VR 头显沉浸式浏览，同时兼容电脑 / 手机平面模式。纯前端单 HTML 文件，打开即玩。

**VR 在线体验**：https://cosmic-flight-vr.app.workbuddy.host/
**平面版（GitHub Pages）**：https://thekeydu.github.io/cosmic-flight/

## 效果特色

- **VR 沉浸飞行**：头显自由环顾，飞船摆动 / 曲速抖动 / 急刹车顿挫作用于载具层，幅度收敛防眩晕
- **贴脸擦肩**：小概率行星正对观察者飞来，贴着眼前呼啸掠过（VR 中冲击力极强）
- **浩瀚宇宙背景**：纯黑深空点缀程序化生成的彩色星云（随机漂移/自转/呼吸）、银河星尘带
- **各式行星**：带彩色星环的土星（暗金环）、海王星（冰蓝环）、冰行星（淡青/淡紫环）、蓝色地球、红色火星等 9 类，全部 Canvas 程序化纹理
- **三种飞行模式**（点击/扳机循环切换）：
  - **平稳巡航**：低速平稳前行，适合观景
  - **狂野模式**：惯性滑行 → 指数爆发加速 → 曲速冲刺 → 瞬间急刹车 + 画面反向拉伸回弹
  - **癫狂模式**：十种动作纯随机接力——随机加速 / 减速 / 急刹 / 加速倒退（**速度可为负，倒退飞行**），每次换挡船头猛甩随机方向
- **曲率空间表现**：加速时前方空间压缩成"奇点区"，近处星体拉成长星轨扫过四周；急停瞬间画面反向拉伸回弹
- **星轨表现**：1600 颗彩色小球（InstancedMesh）高速时沿飞行方向物理拉伸成星轨，正反向飞行均适用

## 操作方式

| 平台 | 操作 |
|---|---|
| VR（Quest 3） | 打开链接 → 点击 ENTER VR → 转头环顾 · **扣动扳机**循环切换 平稳 → 狂野 → 癫狂 |
| 电脑 | 移动鼠标环顾 · 点击循环切换模式 |
| 手机 | 手指拖动环顾 · 轻触循环切换模式 |

## 技术要点

- Three.js r160 + WebXR（`VRButton` / `setAnimationLoop` / `setFramebufferScaleFactor(1.5)` 高分辨率渲染）
- 相机载具分离：VR 中头显控制 camera，飞行姿态施加于外层 Rig
- 速度状态机：狂野模式顺序编排（滑行 → 爆发加速 → 曲速 → 急刹车）；癫狂模式全动作池加权随机，速度可为负（倒退飞行时星体/行星双向回收、曲率视觉按 |速度| 镜像）
- Pointer Events 统一鼠标与触屏交互

## 本地运行

直接用浏览器打开 `index.html` 即可（VR 模式需 HTTPS 环境或 localhost）。
